# 🎯 Number Guessing Game

This is a Python-based Number Guessing Game where players select a difficulty level and try to guess a randomly chosen number within a time limit. Players receive feedback on whether their guess is too high, too low, or very close to the correct answer.

---

## 🧠 Objective

This game helps beginners practice:
- Input handling  
- Control flow (loops, conditionals)  
- Time-based game mechanics  
- Function decomposition and user interaction  

---

## 🚀 Features

- 🔢 Random number generation across different difficulty levels  
- 🧠 Three difficulty levels:
  - Easy (1–50, 60 seconds)  
  - Medium (1–100, 45 seconds)  
  - Hard (1–200, 30 seconds)  
- ⏱️ Countdown timer with real-time updates  
- 🎯 “Very close” hints if guess is within ±10  
- ❌ Option to quit at any time by typing `'q'`  
- 🔁 Replay support after each game round

## 🎮 How to Play

1.	Select a difficulty level: Easy, Medium, or Hard.
2.	Try to guess the random number before time runs out.
3.	You will be told:
	- If your guess is too high or too low
	- If you’re within 10 of the correct number (very close!)
4.	You have a limited time (30–60 seconds depending on difficulty).
5.	Type 'q' at any time to quit the game.
6.	After the game ends, you can choose to play again.
